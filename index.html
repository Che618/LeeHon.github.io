个人简介

我是陈俐宏，西南科技大学软件工程专业 2023 级本科生，专业综合排名 3 / 232，预计将获得推免资格。已通过计算机程序设计能力考试（PAT），成绩 92 分；大学英语四级、六级均通过，具备英文文献阅读基础。

我的研究兴趣集中在大语言模型推理优化与强化学习控制，主要围绕高效推理、知识表示与智能系统三个方向展开，尤其关注如何通过智能化的资源分配和信息压缩策略，提升大模型在复杂推理任务中的效率与精度。

围绕这一方向，我目前有两项核心工作：其一是 Estimate, Then Think（ETT）自适应提示预算框架，通过强化学习动态估计推理所需的 Token 预算，在显著降低计算消耗的同时提升推理准确率；其二是逻辑密度剪枝方法，结合互信息与注意力机制对推理步骤进行重要性量化，实现高达 80% 的 Token 压缩而几乎不损失模型性能。

此外，我在工程实践中完成了非遗数字化保护项目，涉及非结构化文本的实体抽取、关系构建与知识图谱渲染，具备从算法设计到系统落地的完整能力。我对检索增强生成、多智能体协同以及面向工业场景的高效智能系统有着浓厚兴趣，期待持续探索大模型的高效推理与智能决策问题。

2026.05NeurIPS 2026 投稿第一轮评审完成：4 / 4 / 3第三作者

Logic Density Pruning: Mitigating Overthinking via Step-Level Chain of Thought Compression

大语言推理模型在复杂任务中往往通过生成更长的思维链来提升表现，但冗余复述、松散解释和无效分支也会显著推高 token 消耗与推理延迟。针对这一“过度思考”现象，本文提出逻辑密度剪枝（LDP）框架，以互信息（MI）和注意力引用两类信号联合衡量推理步骤对最终答案的贡献，得到可解释的步骤重要性指标。

在剪枝阶段，LDP 使用 Otsu 自适应阈值完成样本内筛选，并通过步级微扰检查验证删除候选步骤是否会显著改变后续生成分布，对关键步骤进行选择性恢复；压缩后的思维链进一步作为监督数据用于微调，形成从剪枝、数据构建到训练的完整流程。在 CommonsenseQA 上应用于 Qwen3-8B 时，推理 token 从 295.5 降至 58.6，减少 80.2%，性能仅下降 1.9%。

我的贡献 在远程服务器中完成 Qwen3 与 DeepscaleR 多分支思维链生成、提取和清洗；使用 Python 批量计算基于希尔伯特-施密特独立性准则的互信息得分，统计“犹豫标记”与“结论标记”的词频分布；主导单一 MI、单一注意力指标的消融实验，并完成 TokenSkip、SBT 等基线的对比训练。DeepscaleR-1.5B 的 Token 消耗降低 49.2%，准确率由 40.8% 提升至 44.3%。

2026.07AAAI 2027 / 审稿中第二作者

Estimate, Then Think: Prompt-Based Token Budgeting for Efficient Inference in Large Reasoning Models

高效推理的关键是在维持推理质量的同时降低 token 消耗，但现有方法多依赖固定提示、人工预算、解码控制或额外训练，较少能同时适应具体问题难度和目标推理模型特性。本文提出 Estimate-Then-Think（ETT）：从目标模型的成功回答中学习，为每个问题预测一个推理预算引导值，并以软提示写入输入端，而非强制限制生成长度。

ETT 先构建预算标签，再通过组相对策略优化（GRPO）训练预算估计器，并通过零样本 ETT-Z 与单样本 ETT-O 将预算传递给不改动参数的目标模型。因此，目标模型无需额外训练成本。在三个大推理模型与四个数学推理基准上，ETT 对比四类高效推理方法取得整体最优结果：ETT-O 实现 33.02% 至 46.70% 的压缩率，同时将准确率提升 1.71 至 5.73 个百分点，Pass@3 提升 3.26 至 4.11 个百分点。

生育支持政策下青年婚育观研究

从问卷数据到婚育意愿的结构模型与群体异质性

本研究聚焦成都市 18 至 35 岁青年群体的婚育状况，考察网络媒体、经济压力、家庭环境和婚育教育等因素共同作用下的婚育观变化与现实困境。研究采用问卷调查与深度访谈相结合的定量、定性方法，对青年婚育意愿、相关认知及其影响机制进行分析。

研究发现，当代青年婚育观呈现理性化、个性化与传统观念交织的特点：整体婚育意愿积极，但在经济压力与现实预期影响下更加审慎。基于结构方程模型、验证性因子分析和聚类方法，研究进一步识别出三类特征群体，为生育支持政策制定、青年发展与人口结构改善提供了参考。

我的贡献 数据处理、核心实证模型构建、抽样方案设计、可视化分析与异质性聚类。

黄明秀、陈俐宏、汪正楠、钟一鸣，《生育支持政策下青年婚育观研究》，《社会经济导刊》，2025。作者单位：西南科技大学计算机科学与技术学院；西南科技大学环境与资源学院。关键词：青年婚育观、青年发展、差异性分析。DOI：10.64216/3080-1486.25.11.003。访问论文
